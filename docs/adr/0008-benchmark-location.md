# 0008 計測は GitHub の無料マシンで行う

状態: 採用

## 決定
公開する数字は GitHub Actions の無料マシンで測る。手元の Mac での計測は参考程度にとどめる。

## 理由
1. 手元の MacBook Air は冷却ファンが無く、回を追うごとに熱で遅くなった(3回で最大 35% 低下)。速いコアと省電力のコアが混ざっていることも、ぶれの原因になる

2. GitHub の無料マシンでは、3回のぶれが最大 3.4%(一覧 0.4%、1件取得 1.3%、更新 0.9%)に収まった

## 影響
1. 当初の「計測は手元の Mac だけ」という決定を置き換える

2. 実行のたびに違うマシンが割り当てられうるので、別の日の結果同士は比べない(毎回全フレームワークを測り直す、ADR 0006)

3. 1コアあたりが遅く、数字は Mac の約7分の1になる。比較には影響しない
